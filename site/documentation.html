Guides pas à pas pour installer SpokaPilote, l'utiliser sur un poste et le déployer sur un parc.

Premiers pas

  1. Installez SpokaPilote depuis la page de téléchargement (x64 ou ARM64).
  2. Analyser ce poste : inventaire et recherche, sans droits administrateur.
  3. Onglet Pilotes → Installer la sélection (SpokaPilote propose de se relancer en administrateur).
spokapilote scan --html rapport.html                    # inventaire + pilotes proposés
spokapilote install --yes                               # manquants + mises à jour (admin)
spokapilote install --missing --exclude NVIDIA --yes    # choisir finement
spokapilote rollback last --yes                         # annuler la dernière intervention
spokapilote driverpack download \\srv\pilotes --model "Latitude 7420"
spokapilote printers export-profile imprimantes.json    # puis : printers deploy
spokapilote schedule enable --weekly lundi --time 12:30 --mode missing
spokapilote policy test --policy driver-policy.json
spokapilote help                                        # toutes les commandes

Codes de sortie : 0 OK · 1 erreur · 2 échec partiel · 3010 redémarrage requis.

Besoin d'aide ?

Une question, un matériel non reconnu, un bug : ouvrez un ticket en joignant si possible le rapport spokapilote scan --json rapport.json.
